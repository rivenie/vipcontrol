# VIP CONTROL · Landing web

Página web de una sola página para VIP CONTROL, agencia de seguridad privada en Lima.

## Contenido

- `index.html` — la página completa (HTML, CSS y JavaScript en un solo archivo).
- `img/` — fotos, logo, escudo y favicon.

No necesita instalar nada: las fuentes (Barlow y Barlow Condensed) se cargan desde Google Fonts.

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `vipcontrol-web`).
2. Sube `index.html`, `README.md` y la carpeta `img/` a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Source** elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
5. En uno o dos minutos la web estará en `https://TU-USUARIO.github.io/vipcontrol-web/`.

Para usar un dominio propio (por ejemplo `vipcontrol.pe`), escríbelo en **Settings → Pages → Custom domain** y configura el DNS del dominio según las instrucciones de GitHub.
